# V3 — Full-feature screening workflow

This directory contains the V3 Google Colab workflow for mouse-dynamics feature screening and feature-set evaluation.

1. Screen all eligible single features.
2. Save and visualise single-feature results.
3. Evaluate candidate feature sets with the same models.
4. Analyse and report the strongest feature-set/model combination.

Do not commit course CSV data, participant data, or identifying information. Only notebooks, configuration, aggregated metrics, figures, and documentation belong here.
